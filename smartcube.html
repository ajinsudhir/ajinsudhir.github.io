    FAQ

    Common questions

    How do I get SmartCUBE?

    Use Request access in Get started. It opens an email with the details filled in, or you can copy the same text into Teams or any other channel. After approval you receive the download and install notes directly.

    Does anything get installed in the cluster?

    No. SmartCUBE runs on your laptop and uses kubectl and your own database accounts.

    Is it safe to use on production?

    Start in read-only mode: every change is blocked. Changes on production clusters always ask for confirmation and are written to the audit log.

    What goes to the AI?

    Only what you send with Ask AI, shown in a preview first, to the AI you choose – Gemini CLI or Claude Code – under your own account.

    Do I need admin rights or Java?

    No. Unzip and run; Java is bundled. Keep the folder somewhere you can write to, not Program Files.

    Ajin Sudhir. Send questions and requests through Request access.
